House rules

01
Evaluation date is an argument. Never a process global.
02
Discounting and forecasting are separate curves.
03
Day counts follow the 2006 ISDA Definitions.
04
Implied vol of a model price returns the input vol.
05
Domain errors raise. They do not return NaN.
