What the numbers mean

The ATM Black–Scholes call with S=K=100, r=5%, σ=20%, T=1 is 10.45058357. That is not a fitted constant. It is S N(d1) − K e^{−rT} N(d2) with d1=0.35, d2=0.15.

Day counts

Act/365F, Act/360, Act/Act ISDA, 30U/360, 30E/360 ISDA. The 2003-11-01 / 2004-05-01 ISDA split is a unit test.

SABR

Hagan 2002 lognormal expansion, ATM and F≠K branches, z/x → 1 when ν=0. Shifted SABR is the same formula on F+s.

Heston

Fang–Oosterlee COS with the little-Heston-trap characteristic function so the complex logarithm stays principal-valued.

Your market

Studio pulls a last print from a demo book, Stooq, or any HTTP JSON venue ({symbol} in the URL). That number is spot — not an order. See Front → Connect a market, or python examples/own_market.py.

Full formula sheet: docs/THEORY.md in the repo. This studio is a local desk, not investment advice, and not a substitute for model validation.
