Proof, not testimonials

Run the evidence yourself.

Argentum does not yet publish customer case studies, reviews, or performance claims. These are reproducible project examples and a template for documenting future work honestly.

Benchmark 01

Closed-form identity

An at-the-money one-year Black–Scholes call with spot and strike 100, a 5% continuously compounded rate, no dividend, and 20% volatility prices at approximately 10.450583572.

argentum vanilla --spot 100 --strike 100 \
  --rate 0.05 --vol 0.20 --texp 1

Then feed the price back to the implied-vol solver and check the 20% round trip.

Benchmark 02

Convention fixtures

The test suite exercises calendar rules, day counts around leap-year boundaries, schedule stubs, curve interpolation, dual-curve swaps, solver limits, and numerical pricing engines.

python -m pytest -q
python -m pytest tests/test_daycount.py \
  tests/test_curve.py tests/test_engines.py

A passing test is evidence about the fixture it asserts — not blanket production validation.

Benchmark 03

Portable risk report

The portfolio command retains normalized inputs, the Argentum version, engine, input digest, aggregate Greeks, tag groups, and scenario PnL in one report.

argentum portfolio examples/sample_portfolio.csv \
  --format json --output risk-report.json

Commit the source portfolio and report together to preserve the path back to the mark.
