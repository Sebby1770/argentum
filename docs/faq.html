Frequently asked questions

Scope, trust, data handling, licensing, and the limits of the commercial offer.

What is Argentum?

Argentum is an MIT-licensed Python toolkit for derivatives pricing, portfolio scenarios, and local market-data prototyping. It combines a typed library, CLI, examples, tests, and a local Studio.

Is Argentum validated for production trading?

No. It is intended for research, teaching, and desk prototyping. A firm must perform its own independent model validation, benchmark review, data controls, security review, and change approval before relying on any output.

Is the core really free?

Yes. The repository is licensed under MIT. Paid offers cover scoped setup and implementation support, not access to hidden pricing engines.

Does Studio upload my portfolio or API key?

Studio runs locally. Feed configuration is stored in the current user's operating-system config directory and secrets are redacted in the UI. A configured quote credential is sent only to the venue URL the user chooses. The separate public website does not connect to local Studio.

Can Argentum connect to my market data?

It can use its deterministic demo book, a public Stooq close, a supported vendor-shaped JSON response, a custom HTTP JSON or CSV endpoint, or a local push endpoint. The user remains responsible for entitlements, field units, timestamps, and stale-data policy.

Which products are covered?

The code includes equity and FX options, selected exotics, bonds, swaps, caps, swaptions, CDS, yield and hazard curves, SABR, SVI, Heston, numerical engines, and risk helpers. Review the repository and theory notes for exact conventions and gaps.

What does the two-business-day response promise mean?

It is a target for the initial reply after a paid support arrangement is accepted. It is not an SLA, 24/7 service, uptime support, incident response, financial advice, or a promise that a particular engagement will be accepted.

How do I install Argentum today?

Clone the GitHub repository and install it in a Python 3.10 or newer environment. Do not rely on a package-index or downloadable release unless one is visibly published on the repository.

git clone https://github.com/Sebby1770/argentum.git
cd argentum
python -m pip install -e ".[dev]"
